# FirstLook landing page

## Run locally

```bash
npm install
npm run dev
```

## Before publishing

Open `src/App.tsx` and replace:

- Support email is set to `usefirstlook@gmail.com`
- `STORE_URL` with the Chrome Web Store URL after approval
- the demo placeholder with your future demo embed

Also update the contact sections in:

- `public/privacy.html`
- `public/terms.html`

## Build

```bash
npm run build
```
